# Setup

Phase 0 intentionally does not require a local development environment. Implementation setup will be added when the corresponding dependencies become real.

## Intended environment

- Primary development: Linux
- Secondary validation: Windows + Docker Desktop
- Reproducible runtime: Docker / Docker Compose

## Planned baseline prerequisites

- Git
- Docker
- Docker Compose

Additional prerequisites will be documented only when the implementation requires them. Local model/runtime setup will be documented separately from paid external-provider configuration.

## Setup rule

A fresh clone must eventually be runnable from this document without relying on undocumented machine-specific configuration.
